PETAL POUNCE — UPDATE 23: POLISHED FLOATING GARDEN ISLANDS

This is a cumulative update. You do not need to install Updates 17–22 first.

UPLOAD / REPLACE THESE FOUR FILES IN BOTH LOCATIONS:

Repository root:
  index.html
  engine.mjs
  game.mjs
  sw.js

dist folder:
  dist/index.html
  dist/engine.mjs
  dist/game.mjs
  dist/sw.js

WHAT CHANGED

• Replaced the purple thorn-bar artwork with hand-drawn floating garden islands.
• Added irregular moss caps, layered soil and stone, hanging roots, rock cracks,
  varied sharp points and tiny sprouts that fit the existing garden artwork.
• Varied island thickness, rock sizes and detail spacing so formations feel
  organic and hand-drawn instead of like repeating mechanical platforms.
• Touching hazard pieces on the same row now render as one continuous island,
  so dense sections look intentional instead of like separate bars.
• Edge-grown hazards appear rooted beyond the screen instead of ending abruptly.
• Preserved the exact Update 22 obstacle positions, reach, spacing, difficulty,
  collision geometry, safe routes, endless progression and calm periods.
• Updated game labels, accessibility text and instructions to say thorn islands.
• Renamed the run HUD from HONEY to SCORE. Flowers add 10 score points each.
• Moved every difficulty notice into the distance HUD to keep the playfield clear.
• Clipped island art to the original obstacle shapes and added a dashed ring
  around the bee during temporary protection.
• Used Flower Garden's smooth bee rendering across all gardens.
• Updated the offline cache to v41.

GAMEPLAY SAFETY

This is a visual-only obstacle update. The proven Update 22 generator and its
collision geometry are unchanged. The new island silhouette reaches the same
danger boundary as the existing hitbox, so the art remains fair and readable.

FALLBACK

If you want to return to the previous look, reinstall the exact Update 22 ZIP.

After uploading, refresh the GitHub Pages site. If an older cached build appears,
close the tab completely and reopen it once.
