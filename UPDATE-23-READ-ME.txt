PETAL POUNCE — UPDATE 23: GARDEN ISLANDS AND BEETLE PATROLS

This is a cumulative update. You do not need to install Updates 17–22 first.

UPLOAD / REPLACE THESE FOUR FILES IN BOTH LOCATIONS:

Repository root:
  index.html
  engine.mjs
  game.mjs
  sw.js

dist folder:
  dist/index.html

  dist/game.mjs

WHAT CHANGED

LATEST REVISION

• Fixed the automatic climb so the screen movement is immediately visible.
  It now starts at 52 pixels per second and eases smoothly toward 72 pixels
  per second as the hidden difficulty progression increases.
• Removed the on-screen distance readout. The center HUD now shows a clean,
  three-digit flower counter, and the duplicate flower display was removed.
• Removed distance from the game-over summary while keeping altitude internally
  for procedural difficulty, hazard density, winds and beetle progression.
• Updated the offline cache to v45.

• Beetles now patrol about 25–30% faster, with a safe maximum horizontal
  speed of 155 pixels per second. They still fly only horizontally and retain
  their permanent escape corridors.
• The playfield now scrolls upward continuously during active play. It starts
  at a steady 52 pixels per second and rises smoothly toward a 72-pixel maximum
  as distance increases; there are no sudden speed levels.
• The camera never reverses downward. A fast-climbing bee can pull it upward,
  while hovering no longer stops the run. Falling completely below the screen
  costs one life and revives the bee at a visible leaf or protected safe point.
• Automatic scrolling pauses with the game and during the short revive delay,
  preventing an unfair moving respawn.

• Lose 10 run points when an uncollected bloom scrolls below the playfield.
  Each missed flower is counted once and removed from the run. The score can
  go below zero. The flower bank is separate from the run score.
• A brief on-screen notice shows the points lost. Personal best uses the score
  at game over or when you return to the title.

BEETLE PATROLS

• Added hand-drawn rose-colored beetles with shell details, legs and flying wings.
• Beetles patrol horizontally at fixed heights and reverse direction smoothly.
• Patrol density increases with altitude. The first patrol is above 35 meters.
• Every patrol reserves a 105-pixel escape corridor and clears rocks, flowers
  and respawn leaves. Maximum horizontal patrol speed is 120 pixels per second.
• Beetle collisions cost one life and use the existing automatic revival.

• Replaced the purple thorn-bar artwork with hand-drawn floating garden islands.
• Added irregular moss caps, layered soil and stone, hanging roots, rock cracks,
  varied sharp points and tiny sprouts that fit the existing garden artwork.
• Varied island thickness, rock sizes and detail spacing so formations feel
  organic and hand-drawn instead of like repeating mechanical platforms.
• Touching hazard pieces on the same row now render as one continuous island,
  so dense sections look intentional instead of like separate bars.
• Edge-grown hazards appear rooted beyond the screen instead of ending abruptly.
• Added moving hazards to the island course for additional difficulty.
• Updated game labels, accessibility text and instructions to say thorn islands.
• Renamed the run HUD from HONEY to SCORE. Flowers add 10 score points each.
• Moved every difficulty notice into the distance HUD to keep the playfield clear.
• Clipped island art to the original obstacle shapes and added a dashed ring
  around the bee during temporary protection.
• Used Flower Garden's smooth bee rendering across all gardens.

GAMEPLAY SAFETY

Patrols are checked against rocks, flowers and respawn leaves. Every patrol has
an escape corridor. Neighboring patrols also allow time to steer between their
escape openings. Beetle hits trigger automatic revival and brief protection.

FALLBACK

If you want to return to the previous look, reinstall the exact Update 22 ZIP.

After uploading, refresh the GitHub Pages site. If an older cached build appears,
close the tab completely and reopen it once.
