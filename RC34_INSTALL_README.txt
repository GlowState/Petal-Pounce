PETAL POUNCE · RC34 — NEON GARDEN
==================================

ADD-ON THEME: Neon Garden is a permanent optional unlock in the existing Garden Shop.
Price: 180 banked flowers. Once purchased, use the Shop to equip Neon Garden.

VISUAL DESIGN
* Dark navy/indigo sky, subtle neon clouds, small stars and crescent moon.
* Landing leaves have CYAN glowing edges.
* Dangerous thorn hazards are MAGENTA with angular neon details.
* Pink neon flowers, neon-edged beetles, a light bee glow and HUD accent treatment.
* Existing user-selected bee skin, joystick, Fly control, hazards and collisions unchanged.
* Other gardens and your RC33 main menu image are unchanged.

INSTALL
1. Extract this ZIP.
2. In the GitHub repository root, replace these seven files:
   index.html, game.mjs, scenery.mjs, profile.mjs, joystick.css, sw.js,
   and ADD the new neon-art.mjs file.
3. Repeat with matching files inside dist/.
4. Commit the changes. Close and reopen the Home Screen app after deployment.
5. Open Garden Shop, unlock Neon Garden for 180 flowers, then equip it.

SAFE DATA
Existing local save keys, flower balances, records, purchases, unlocks and
other garden graphics remain unchanged. Existing players do not need to reset.
This release does not change engine.mjs, flowers.mjs, input code, collision
geometry, scoring, or the difficulty curve.

VALIDATION
Node syntax checks passed. Direct theme-drawing tests passed, including the
Shop purchase/equip data and prior themes. A renderer-generated preview is
available separately; phone Safari deployment is not verified here.

This is a targeted RC34 update, not the entire repository.
