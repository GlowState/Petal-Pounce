PETAL POUNCE — UPDATE 18: HAZARD DENSITY
========================================

THIS IS A CUMULATIVE UPDATE
Install this directly over Update 17. You do not need to reinstall earlier
updates first.

INSTALL
1. Replace index.html, engine.mjs, game.mjs, and sw.js in the repository root.
2. Replace those same four files inside the dist folder.
3. Commit and push to GitHub.
4. Close and reopen the game on iPhone so the v33 cache can activate.

WHAT CHANGED
- Difficulty now comes mainly from more hazards instead of extreme speed.
- Hazard targets increased by 10 percentage points in every band.
- Maximum speed was reduced from 2.0x to 1.28x.
- Every generated chunk deliberately places hazards in all three lanes.
- An individual row still occupies no more than two lanes, so one escape lane
  always remains.
- Paired walls rotate their opening instead of repeatedly favoring one lane.
- Single hazards prioritize lanes used least recently.
- Ordinary leaves can spawn in any lane rather than following a staircase.
- Leaves have wider size variation and random horizontal placement inside
  their lane.
- Flower chains remain smooth and readable so the run has a rhythm.
- Hazard walls and risky 3-flower bait traps remain part of that rhythm.
- The invisible safe route can move only one lane per row, even when a leaf
  appears farther away. This keeps random placement from causing impossible
  jumps.
- Help text now explains the hazard-first difficulty system.
- Cache version increased to v33.

IMPORTANT DESIGN RULE
“Hazards in every lane” means every generated section uses all three lanes.
The game never fills all three lanes on the same horizontal row, because that
would cause an unavoidable hit.
