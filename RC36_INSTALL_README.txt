UPLOAD
1. Upload every root file in this package to the matching root of your site.
2. Upload every file inside dist/ to the matching dist/ folder.
3. Replace files when GitHub asks.
4. Wait for GitHub Pages to finish deploying, then open the site once in Safari.
5. Close and reopen an existing Home Screen copy after the deployment finishes.

The image and CSS files neon-ui-backdrop.png and neon-ui.css are required.
