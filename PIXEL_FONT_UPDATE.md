# Petal Pounce — Pixel Typography Update

All text in the game, HUD, menus, shop, help screen, and privacy page now uses Jersey 20 when the website is online.
Jersey 20 is licensed under SIL Open Font License 1.1, which permits use in commercial projects.

Important: the font in the reference screenshot is **Player 2 by Letterlays**. Its free demo is **not licensed for commercial use** and is not included. The exact Player 2 typeface requires an appropriate purchased license from its rights holder.

Jersey 20 is loaded via Google Fonts, so a live internet connection is required to see it. Offline/Android builds use the CSS fallback until a properly licensed local font is obtained and configured. No font binaries are included in this package.

Upload the contents of the `dist/` folder to the same GitHub paths, preserving the folder name. Do not upload a ZIP without extracting it.
