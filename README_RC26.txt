PETAL POUNCE RC26 — COMPLETE MENU FIX BUILDER
=================================================

Direct GitHub uploads are blocked by the connected GitHub integration.

To create the ready-to-upload RC26 ZIP:
1. Open Petal_Pounce_RC26_Builder.html in Safari or another regular browser.
2. Tap Build & Download RC26 ZIP. This fetches the four currently approved
   public repository files, patches them and downloads a new ZIP.
3. Extract that new ZIP. Upload its four root files to GitHub root and its
   four dist/ files into GitHub dist/.
4. Commit and reopen the game after deployment.

The builder refuses to modify unknown/changed source files. It does not
require login, tokens, credentials or access to private data. It only
reads the public repository files. The update is visual/menu-state only;
gameplay is unchanged.
