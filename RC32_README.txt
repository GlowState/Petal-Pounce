- index.html
- game.mjs
- joystick.css
- sw.js
- petal-pounce-main-menu.png

THEN UPLOAD THE SAME 5 FILES FROM THE dist/ FOLDER
TO YOUR REPOSITORY'S dist/ FOLDER.

THE BACKGROUND HAS NO PAINTED MENU BUTTONS.
ALL FOUR MENU BUTTONS ARE LIVE, INTERACTIVE HTML ELEMENTS:
- PLAY: starts existing game / initial tutorial if first launch.
- SHOP: opens existing Garden Shop.
- SETTINGS: opens existing options with Sound, Shop, How to Play,
  High Scores, Achievements and Credits.
- CREDITS: opens existing Credits screen.
- Live saved personal-best score is kept and shown at top of menu.

The existing game engine, physics, controls, collection and scoring are
unchanged. A paused run places control visuals beneath its popup so the
buttons no longer appear over it.

Cache build updated to 84 (RC32). Close and reopen the app after deployment.
Do NOT delete the Home Screen app to refresh it; local progress may be lost.

Verification: file integrity, JS syntax, DOM target/handler mapping and
responsive static layout were checked. Live iPhone testing remains necessary.
