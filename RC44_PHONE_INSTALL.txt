PHONE INSTALL (existing GlowState/Petal-Pounce repository)
1. Download this ONE ZIP file, unzip it on your phone.
2. On GitHub, go to GlowState/Petal-Pounce (main branch).
3. Replace the files in the same paths as inside this ZIP:
   engine.mjs, game.mjs, scenery.mjs, index.html, sw.js
   and the same five under dist/.
4. To keep Android CI validation correct, also replace
   scripts/verify-android-assets.mjs and tests/engine.test.mjs.
5. Do not remove unrelated files or move the contents of dist/ to root.
6. Reload your live game. RC44 uses web cache BUILD 95.
7. Rebuild Android AFTER updating dist/, since it packages files from dist/.

This pack assumes RC42 or RC43 is already installed. If you have RC43
already, this still safely replaces the required files with the RC44 versions.
GitHub mobile cannot deploy a .zip by itself; upload the files inside it
using their correct folder paths. Only these twelve replacement paths are needed.
